# Reflection

## What Went Well

- The audit engine became much more structured than I initially planned
- Breaking components into smaller reusable files improved development speed later
- Rule-based recommendations worked better than relying fully on AI responses
- The UI and report sections became cleaner after multiple iterations

## Challenges

- I started with very little Next.js and TypeScript knowledge, so learning while building slowed development initially
- PDF export caused many issues because some modern CSS color formats were unsupported
- Hydration and build issues took longer to debug than expected
- External AI APIs were unreliable because of rate limits and quota restrictions

## What I Would Improve

- Make optimization recommendations more dynamic instead of partially hardcoded
- Improve mobile responsiveness further
- Add proper analytics and usage tracking
- Improve PDF formatting and export quality
- Add better production-level security and rate limiting

## Biggest Learning

I learned that building a real product involves much more debugging, restructuring, and decision-making than just writing frontend code.
